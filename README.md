# Final Assignment: Analyzing Historical Stock and Revenue Data and Building a Dashboard

This repository contains the complete implementation and executed Jupyter Notebook for the Coursera / IBM Applied Data Science final assignment: **"Analyzing Historical Stock/Revenue Data and Building a Dashboard"**.

## Project Highlights
- **Stock Data Extraction (`yfinance`)**: Extracted historical stock market data for **Tesla (`TSLA`)** and **GameStop (`GME`)**.
- **Web Scraping (`BeautifulSoup`)**: Scraped and cleaned quarterly revenue tables from HTML financial data.
- **Interactive Visualizations (`Plotly`)**: Created dual-panel dashboards comparing historical share price versus historical revenue trends over time using `make_subplots`.

## Notebook Files
- `Analyzing_Historical_Stock_Revenue_Data_and_Building_a_Dashboard.ipynb`: Fully executed Jupyter Notebook with all outputs and interactive graphs displayed.
- `Final_Assignment.ipynb`: Mirror copy formatted for submission.
